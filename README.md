# Tor Aphisak — Digital Media & Marketing

Personal portfolio: a 3D scroll website (three.js) covering motion graphics, video, graphic design, web and Google Ads work.

## Files
- `index.html` — page content
- `style.css` — colours, fonts, layout
- `main.js` — project cards (edit the `projects` list) and scroll effects
- `scene.js` — 3D shapes and scroll animation
- `assets/` — images

## Run locally
Open the folder in VS Code and use the Live Server extension, or any static file server.
